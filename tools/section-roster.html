Put someone on — the sheet starts empty. The whole platoon is in the dropdown, by section, and picking a name adds him with his C/S, E number, role and ticks already filled in. Typing into a name box does the same: the list suggests as you type. Add person gives you a blank row for anyone the list has never heard of.
RAF — the RAF pair take it in turns on the Main Gate. Whoever isn’t on the gate works Ops on OG and QRF only, never CG, and holds no vehicle.
Fixed on MG is on the Main Gate every shift alongside them. Everyone left fills AB115, VEH 1 and VEH 2.
MPGS — no weapon works Ops on OG and QRF only, same as the RAF, but still counts for Gd Cdr and R3 if you tick those.
VEH 1 and VEH 2 go to Ptes and LCpls only. It reads the rank in front of the name, so keep writing them as “LCpl Jewitt”, “Pte Thuku” and so on. Cpls and above take AB115.
R3 by shift — leave on Auto to spread it round, or pin a name to a particular shift. A man pinned to R3 is passed over for Gd Cdr that shift, so both settings hold at once.
Build roster reshuffles who lands where, but never breaks the rules above. Press it until you get a spread you’re happy with. Everything else on this panel updates the sheet as you type and keeps the same layout, so fixing a name doesn’t cost you the roster.
Save as PDF builds a proper A4 file with one day per block and never splits a table across pages. Download sheet saves a standalone file you can print from your browser, and Save as image gives you a PNG you can long-press to share.
Every cell on the sheet below can be typed over before you save. What you type stays put while you change things up here; Build roster clears it, because the duties underneath it moved.
The whole sheet is kept on this device, so it is still here next time you open the page. Start again empties the sheet back to nobody on.
